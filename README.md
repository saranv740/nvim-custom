# NEOVIM CONFIG

## Minimum version: 0.12.x

## Dependencies:
    - mingw64
    - make
    - ripgrep
    - lua
    - luarocks
    - Nerd font
    - git
    - lazygit
    - python
    - tree-sitter-cli

### Windows deps install commands
**Note**: chocolatey must be installed beforehand.

```bash
# These dependencies are available via chocolatey
choco install mingw
choco install make
choco install ripgrep
choco install lua
choco install luarocks
```
